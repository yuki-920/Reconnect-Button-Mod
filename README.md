# Reconnect Button Mod

Adds a **Reconnect** button to the disconnect screen.  
No more going back to the server list just to rejoin — simply click Reconnect!

## Features
- Adds a Reconnect button below the "Back to server list" button on the disconnect screen
- Works on both the "Connection Lost" screen and the "Failed to connect to the server" screen
- Supports resource packs and custom translations
